# 大阪府広告代理店・マーケティング会社 営業リスト

SKY DRONE株式会社の制作パートナー営業用リスト

## ファイル構成

- `大阪府_広告代理店_マーケティング会社_営業リスト_YYYYMMDD.xlsx` - 営業リストExcelファイル
- `create_sales_list.py` - リスト生成スクリプト

## リストの内容

現在、以下のカテゴリの会社を68社収録しています：

### 対象企業

- 広告代理店（Web広告・総合広告）
- Webマーケティング会社
- SEO会社
- SNSマーケティング会社
- Web制作会社・LP制作会社
- 映像制作会社
- ブランディング会社
- デザイン会社

### 優先度

- **優先度A（62社）**: 社員数5～50名を中心とした、制作外注の可能性が高い企業
- **優先度B（4社）**: 社員数50名以上だが、外注可能性がある企業
- **優先度C（2社）**: 大手企業（参考情報）

## Excelの機能

- 1行目：太字＋背景色（ヘッダー）
- フィルター設定：全列にフィルター適用
- 1行目固定：スクロール時もヘッダー表示
- 列幅自動調整：見やすい幅に調整済み
- URLリンク：クリックで直接アクセス可能
- メールリンク：クリックでメーラー起動（mailto形式）

## 使い方

### 1. 営業前の準備

1. 優先度Aの企業から順番にコンタクト
2. 公式サイトを確認し、最新情報をチェック
3. 問い合わせページまたはメールアドレスを確認
4. 事業内容を確認し、SKY DRONEのサービスと関連性を判断

### 2. 情報の追加・更新

「要確認」となっている項目は、各社の公式サイトで以下の情報を確認・更新してください：

- **メールアドレス**: 「お問い合わせ」ページで確認
- **電話番号**: 「会社概要」「アクセス」ページで確認
- **郵便番号・住所**: 「会社概要」「アクセス」ページで確認
- **社員規模**: 「会社概要」「採用情報」ページで確認
- **採用ページ**: 「採用情報」「リクルート」リンクを確認

### 3. 営業活動の記録

営業活動の進捗を以下の列に記録してください：

- **営業状況**: 未送信 → メール送信済 → 返信待ち → 商談設定 など
- **送信日**: メール送信日を記入（例：2026/07/05）
- **返信**: あり/なし、または返信内容の要約
- **商談日**: 商談が設定された場合の日時
- **備考**: その他メモや特記事項

## 情報収集の限界について

本リストは、2026年7月時点のWeb検索により収集した公開情報をもとに作成しています。
以下の点にご注意ください：

### 情報の精度

- Web上で公開されている情報のみを収録
- 一部企業は詳細情報が非公開のため「要確認」と記載
- 社員数は推定値を含む場合があり
- 最新情報は各社の公式サイトで確認することを推奨

### 追加調査が必要な項目

多くの企業で以下の情報が公開されていないため、営業担当者が直接確認する必要があります：

1. **営業メールアドレス**: ほとんどの企業は問い合わせフォームのみ
2. **担当部署の連絡先**: 直接電話で問い合わせが必要
3. **外注予算・制作頻度**: ヒアリングが必要
4. **現在の制作パートナー**: 関係構築後に確認

### さらに多くの会社をリストアップするには

300社以上のリストを作成するには、以下の方法を検討してください：

1. **業界団体のデータベース**
   - 日本アドバタイザーズ協会（JAA）
   - 日本広告業協会（JAAA）
   - 日本インタラクティブ広告協会（JIAA）

2. **企業検索サービス**
   - 帝国データバンク
   - 東京商工リサーチ
   - ランスタッド（企業データベース）

3. **営業リスト専門サービス**
   - Salesforce Data.com
   - HubSpot
   - Sansan

4. **手動検索**
   - Google検索で「大阪 ○○会社 一覧」
   - 求人サイト（Indeed、リクナビなど）で採用企業を検索
   - SNS（LinkedIn、Wantedly）で企業検索

## 除外企業

以下の超大手企業は除外しています：

- 電通
- 博報堂
- ADK
- サイバーエージェント
- オプト
- その他売上100億円以上の大手広告代理店

## 更新方法

リストに新しい会社を追加する場合は、`create_sales_list.py`を編集してください。

### スクリプトの実行方法

```bash
# 必要なライブラリをインストール
pip install openpyxl

# スクリプトを実行
python3 create_sales_list.py
```

実行すると、`大阪府_広告代理店_マーケティング会社_営業リスト_YYYYMMDD.xlsx`ファイルが生成されます。
