# 和心料理スクール ホームページ

日本料理スクールの美しいホームページとAIチャットボット統合システムです。

## 📁 プロジェクト構造

```
/
├── homepage/              # ホームページファイル（新規作成）
│   ├── index.html        # メインHTML
│   ├── css/
│   │   └── style.css    # スタイルシート
│   ├── js/
│   │   └── script.js    # JavaScript（チャット機能含む）
│   └── images/          # 画像フォルダ
├── server.js             # バックエンドサーバー（既存）
├── package.json          # 依存関係（既存）
└── README.md            # このファイル
```

## 🚀 セットアップ方法

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定

OpenAI APIキーを設定してください：

```bash
export OPENAI_API_KEY="your-api-key-here"
```

### 3. サーバーの起動

```bash
npm start
```

サーバーは `http://localhost:3000` で起動します。

### 4. ホームページの確認

ブラウザで以下のURLにアクセス：

- ホームページ: `http://localhost:3000/homepage/index.html`

## ✨ 機能

### ホームページ機能
- ✅ **レスポンシブデザイン** - スマホ・タブレット・PCに対応
- ✅ **モダンUI** - グラデーション、アニメーション搭載
- ✅ **スクロールアニメーション** - 要素が滑らかに表示
- ✅ **ナビゲーション** - スムーズスクロール機能
- ✅ **コース紹介** - 出汁、寿司、天ぷらの3コース
- ✅ **ギャラリー** - レッスン風景の表示
- ✅ **お問い合わせ** - AIチャット統合

### AIチャットボット機能
- ✅ **AI自動応答** - 一般的な質問に自動で回答
- ✅ **人間へのエスカレーション** - 複雑な質問は自動でスタッフ対応に切り替え
- ✅ **リアルタイム会話** - 瞬時に応答
- ✅ **日本語対応** - 完全日本語UI

### エスカレーション条件
以下の場合、自動的に人間（スタッフ）対応に切り替わります：
- アレルギー相談
- 日程調整
- キャンセル手続き
- クレーム対応
- その他複雑な問い合わせ

## 🔧 カスタマイズ

### 色の変更
`homepage/css/style.css` の `:root` セクションで色を変更できます：

```css
:root {
    --primary-color: #d4282d;    /* メインカラー */
    --secondary-color: #1a1a1a;  /* セカンダリカラー */
    --accent-color: #f4a460;     /* アクセントカラー */
}
```

### コンテンツの変更
`homepage/index.html` を編集してテキストや画像を変更できます。

### AIプロンプトの変更
`server.js` の `systemPrompt` を編集してAIの応答をカスタマイズできます。
